# mailroom-live

A learning project built while working through **Chapter 13: Programming Fundamentals in the AI Era** of *The AI Agent Factory* (Panaversity), using the PRIMM-AI+ method.

## Requirements

- [uv](https://docs.astral.sh/uv/) (it installs Python 3.15 for you)

## Run it

```bash
uv sync              # create .venv and install dev tools
uv run mailroom-live # run the app
uv run pyright       # type-check (strict mode)
```

See [AGENTS.md](AGENTS.md) for the rules any AI coding agent must follow in this repo.
